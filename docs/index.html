What is LinkedIn Connection Cleaner?

A local Node.js toolkit for exporting, understanding, and cleaning your LinkedIn network.

LinkedIn doesn't offer a great way to bulk-manage thousands of connections. This project fills that gap with four command-line tools that automate the tedious parts while keeping your data on your own computer.

Download → Analytics → Scrape (optional) → Remove

Recommended workflow

  • Export your network to connections.csv
  • Explore the analytics dashboard
  • Optionally classify sales/recruitment contacts
  • Dry-run removals, then execute

Requirements

  • Node.js 18 or later
  • A LinkedIn account
  • macOS, Windows, or Linux

Install & configure

Clone the repo, install dependencies, and set your LinkedIn email.

git clone https://github.com/bhealy/linkedin.git
cd linkedin
npm install
cp .env.example .env

Edit .env and set your LinkedIn login email:

LINKEDIN_EMAIL=you@example.com
💡
Optional: paste your li_at cookie from browser DevTools (Application → Cookies → linkedin.com) into .env to skip the login prompt.

On first run, a Google Chrome window opens via Puppeteer. Log in to LinkedIn if prompted — your session is saved in .linkedin-session/ for future runs. Your installed Chrome is used rather than Puppeteer's bundled build, because the bundled build advertises itself as automated and draws a captcha.

Download your connections

Export your full 1st-degree network to CSV using LinkedIn's connections-page pagination API.

npm run connections:download

The downloader opens your connections page, parses the initial batch from the page HTML, then paginates through the rest using LinkedIn's SDUI API endpoint. Results are written to connections.csv after every batch.

⚡
5,000 new contacts per run. Each run fetches up to 5,000 new connections — not 5,000 total. Your CSV grows across runs (5k → 10k → 15k…). Run the command repeatedly until the summary says all connections are downloaded.
CommandPurpose
npm run connections:downloadContinue or start download
npm run connections:download:statusShow saved progress
npm run connections:download:freshReset CSV and state
node download-connections.js --limit 100Fetch only 100 new (for testing)
node download-connections.js --resumeContinue if wrongly marked complete

CSV columns: name, title, profile_url, vanity_name, connected_on

Pagination requests use a random 1–10 second delay between batches to reduce rate-limit risk. A live progress bar shows status in your terminal.

Generate analytics

Turn your CSV into a beautiful, self-contained HTML dashboard.

npm run connections:analytics:open

This builds connections-analytics.html — a single file you can open in any browser. All data is embedded locally; no server required.

Dashboard includes

  • Network growth timeline by month
  • Seniority & role breakdown from headlines
  • Top companies and keywords
  • Weekday connection patterns
  • Searchable, filterable contact table

Custom paths

node generate-connections-analytics.js \
  --input connections.csv \
  --output report.html \
  --open
🔐
The analytics file contains your full contact list. Keep it private — don't upload it to public hosting.

Scrape by title (optional)

Classify sales and recruitment contacts via LinkedIn people search — useful if you want title-based filtering before removal.

npm run scrape:sales

Unlike the connections downloader, this tool searches LinkedIn people search using a keyword × geography grid defined in search-plan.json. Each cell finds up to ~250 results, working around LinkedIn's search caps.

Each contact is classified as:

sales recruitment sales_and_recruitment not_target

Output goes to sales-connections.csv with columns: name, title, profile_url, status, search_id, geo.

npm run scrape:status        # grid progress
npm run scrape:sales:fresh   # reset progress, keep CSV
💡
If you only want to export and explore your network, skip this step. The downloader + analytics path is enough for most users.

Remove connections

Bulk-remove unwanted contacts — always dry-run first.

# Dry run — shows who would be removed, makes no changes
npm run connections:remove -- --status spam --limit 20

# Execute removals
npm run connections:remove -- --execute --status spam --limit 20

--status spam targets all of sales, recruitment, and sales_and_recruitment in one pass. You can also target individual statuses or not_target.

FlagDescription
--executeActually remove (omit for dry run)
--status <value>Filter: spam, sales, recruitment, not_target, etc.
--limit <n>Max removals this run
--ignore-company <name>Skip titles mentioning this company
--csv <path>Use a different CSV file
--freshClear removal history
⚠️
Removals are permanent on LinkedIn. Always dry-run first with a small --limit. Removals are spaced ~1.2 seconds apart to avoid rate limiting.

Privacy & security

Your data stays on your machine. Here's how the tools handle credentials and exports.

🔒 Local-only execution

Puppeteer runs Chromium on your computer. LinkedIn API calls use your browser session cookies — nothing is proxied through a third party.

🚫 Never commit secrets

.env, CSV exports, analytics HTML, and .linkedin-session/ are gitignored. Never push these to GitHub.

📁 Sensitive outputs

connections.csv and connections-analytics.html contain personal data about your network. Store and share them carefully.

🌐 This website

This documentation page is static HTML on GitHub Pages. It does not run the tools or collect any data — you run everything locally via the CLI.

Architecture

How it works under the hood

A quick technical overview for the curious.

Connections downloader

Uses Puppeteer to maintain a LinkedIn session, then calls POST /flagship-web/rsc-action/actions/pagination on the connections page. Responses are React Flight / SDUI streams parsed for name, title, profile URL, and connection date.

People search scraper

Navigates LinkedIn people search for each keyword × geography cell in search-plan.json. Classifies headlines containing sales or recruitment terms. LinkedIn caps search at ~250 results per query; the grid works around this.

Analytics engine

Reads connections.csv, computes aggregates (growth, seniority, roles, companies), and renders a self-contained HTML file with embedded Chart.js charts and a filterable table.

Bulk removal

Calls LinkedIn's SDUI remove-connection action for each vanity_name in your CSV, filtered by status. Tracks removed profiles in state so reruns skip them.
